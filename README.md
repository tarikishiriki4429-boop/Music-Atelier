# Music Atelier v0.1.0

iPad Safari / GitHub Pages対応。伴奏を別トラックで編集し、Melody Atelier→Voice Atelier→Music Atelierをファイルだけで接続する実動作のプロトタイプです。商用サンプリング楽器ではなくWeb Audio APIのローカル音源合成です。外部CDN、音声送信、サーバー側処理、課金はありません。

## 配置（Netlify不要）

1. このZIPを解凍します。
2. `index.html`, `app.js`, `styles.css`, `sw.js`, `icon.svg`, `manifest.webmanifest`, `README.md` を新しいGitHubの公開リポジトリのルートに置きます。ZIPそのものを置いても動きません。
3. Settings → Pages → Deploy from branch → main / (root) → Save。
4. 公開された `https://ユーザー名.github.io/リポジトリ名/` をiPad Safariで開き、共有 → ホーム画面に追加。最初の読み込みにはネット環境が必要です。

## Melody・Voice連携

1. Melody Atelier v0.4.0以降の「Voice Atelierへ渡すZIP」を保存します。
2. Music Atelierの「Melody Atelierから」で読み込みます。歌詞、曲名、拍子、BPM、ブロック、編集可能なコードデータ、メロディー参照音符を読み込みます。Melodyの `guide.wav` 自体は読み込みません（コードと旋律が混ざるため）。
3. Music Atelierで音を編集するか「コードから伴奏生成」を押して4楽器の音符を作ります。
4. 「Voice Atelierへ渡すZIP」を保存し、Voice Atelierの「Melody連携ZIPを取り込む」で開きます。この音声はVoiceでは「♪ メロディーガイド」と表示されますが、中身は伴奏と必要に応じてメロディーを含む混合ガイドです。
5. Voice Atelierではリードなどを録音し、「ガイド音声も完成WAVに混ぜる」を **OFF** にして24bit WAVを書き出します。これでガイド音声のない歌声だけを入手できます。
6. Music Atelierの「Voice Atelierの歌声」にWAVを入れます。音声は曲先頭0秒から配置されるため、絶対時間の配置を維持できます。再生位置を微調整することもできます。最終ミックス WAVを書き出します。

**重要**: Voice Atelierに「Melody連携ZIPを取り込む」と既存の歌声や曲が置き換わります。読み込み前にVoice Atelierの「プロジェクト一式ZIPで保存」を使用してください。

## 仕様

- 楽器：ピアノ、合成エレキギター、合成ベース、ドラム4音、ヴァイオリン、シンセ（すべてローカル合成）。
- ピアノロール：ノート追加、ドラッグ移動、右端伸縮、複数選択、矢印微調整、複製・削除、強弱、Undo/Redo。選択モードで空白をドラッグすると、iPadの指で横・縦スクロールできます。
- 初めて試す場合は「▶ デモ曲で試す」でオリジナルの短いサンプルを読み込み、伴奏を試聴できます。「＋ 新しい曲」で初期状態に戻せます。
- 音声：音声WAV/M4A/MP3など、Safari側でデコードできる形式のみ。データはブラウザー内で保持、IndexedDBへローカル保存。
- ミックス：トラック別のゲイン、左右定位、フィルター（トーン）、簡易リバーブ、ミュート、ソロ、コンプレッサー。
- 出力：完成ミックス24bit WAV、伴奏24bit WAV、Voice連携用の無圧縮ZIP（16bit WAV 32kHz）、編集データと読み込んだ音声を含むバックアップZIP。
- 編集と出力の長さ：最大6分。音声ファイル80MB以内、最大18トラック、Voice連携ブロック最大40。
- 端末/ブラウザー依存の自動保存は消える可能性があります。プロジェクトZIPを保存してください。
- iPad Safari実機による互換性・長時間出力・録音経路の検証は未実施。初期の試作版です。

## 動作テスト

- `python3 -m http.server 8765` でローカル配信し、ブラウザーで `http://localhost:8765` を開けます（サービスワーカーはHTTPSでのみ登録）。
- インターネット通信を切ったあとも、サービスワーカーのキャッシュ済みファイルは利用できる設計です。自動保存はURL/ブラウザーごとで、別のリポジトリURLに移しても自動移行しません。
